# VELOCITY: SHIFT

A browser-based first-person movement game. Sprint, slide, dash, double jump, wall-run and vault —
then chain it all together.

Work in progress: see `CHANGELOG.md` for the phase-by-phase status. Full documentation lands with the first release.

```bash
npm install
npm run dev      # play locally
npm test         # headless movement + level simulations
npm run build    # production build in dist/
```
